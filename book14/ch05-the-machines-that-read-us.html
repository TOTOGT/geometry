The Machines That Read Us

Four tools, one textbook, and an experiment with the subject tags

This corpus reads itself with four small programs. One finds file names, one files pages under sections, one links pages that share ground, and one collects the series' own keys. A standard textbook of language processing has a name for each of them, and a way to measure each. This chapter measures them the way the textbook would.

What the corpus's record showsEvery one of these tools first failed on precision: it reported things that were not there, such as CSS read as file names, a download box read as a citation, or a legend read as an operator. Each failure was found and fixed. Recall, the things a tool silently misses, was never measured, because measuring it needs a gold standard that nobody has built. COMPUTED
2 · An experiment

Could a machine have filed the pages?

An editor gave every chapter a subject tag (MATHEMATICS · PURE, BIOLOGY · SYSTEMS…). The script asks whether the page text alone predicts the field. It takes 472 tagged pages in the 12 fields that have at least ten pages each, splits them ten ways, trains on nine parts and tests on the tenth. COMPUTED

Both clearly beat the baseline, so the sections are partly written into the vocabulary. But J&M warn about exactly this situation. A classifier that "stupidly classified every tweet" as the majority class scores 99.99% on a skewed set (p.113), which is why they report F1 per class. Per field, naive Bayes gives: CITED

The macro-F1 is 0.391. Mathematics has recall 0.93 and precision 0.63: the classifier files almost anything mathematical-looking under mathematics, and 28 physics pages go there. Education, series apparatus, method, history and philosophy are almost never recovered. COMPUTED

What that says about the tagsThe fields the machine cannot find are the ones defined by purpose rather than vocabulary. A teaching page about the Lorenz system uses the words of physics, and a method page uses the words of whatever it audits. So the magazine's sections carry information the text does not: they record why a page exists, not only what it is about. That is an argument for keeping the tags editorial, as R25 already does. 3 · The patterns

The key register (Key Register) is a Hearst-style pattern reader: "K: threshold" plays the role of "NP such as NP" (p.476). In the by-eye sample of Chapter 4, 19 of 20 hits were true glosses, so precision is high on a small sample. Recall is unknown, because glosses written as "K, the threshold," or in prose are not caught. OPEN

Not establishedThe tags are an editor's decisions, not facts about the pages, so "accuracy" here means agreement with those decisions. One deterministic ten-fold split was used, with no stemming and no stop list, so a better model would score higher. Recall for any of the four tools needs a hand-built gold set, which does not exist yet. WANTED
