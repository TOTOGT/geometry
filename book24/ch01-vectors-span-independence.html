Vectors, span, independence

Two arrows in the plane either point along one line or they don’t. Everything in this book is a way of making that precise and then asking what survives when the plane is replaced by something larger.

drag the three dots · teal = v1 · gold = v2 · white = w

1 · The two definitions

Over a field F (for now: the real numbers), the vectors v1, …, vk are linearly independent when the only way to write the zero vector as c1v1 + … + ckvk is with every ci = 0. Their span is the set of all such combinations. Independence says the list has no redundancy, and span says how much room the list reaches.

In the plane, take v1 = (a, c) and v2 = (b, d) as the columns of a matrix. The plate above draws them, shades the parallelogram they span, and reads off the determinant.

2 · The plane criterion

StatementTwo vectors v1 = (a, c) and v2 = (b, d) in the plane are independent exactly when ad − bc ≠ 0.

If the determinant is not zero. Suppose c1v1 + c2v2 = 0, that is, c1a + c2b = 0 and c1c + c2d = 0. Multiply the first by d and the second by b and subtract: c1(ad − bc) = 0. Multiply the second by a and the first by c and subtract: c2(ad − bc) = 0. With ad − bc ≠ 0 both ci are zero.

If the determinant is zero. Then (c1, c2) = (d, −c) gives a combination equal to zero in both components, as does (b, −a). If c and d are not both zero the first is nonzero; otherwise, if a and b are not both zero, the second is; and if all four entries are zero, (1, 0) works. In every case there is a nonzero combination that vanishes, so the pair is dependent. □

3 · Coordinates

When the determinant D = ad − bc is not zero, every w = (w1, w2) in the plane is a combination of v1 and v2 in exactly one way:

c1 = (w1·d − b·w2) / D c2 = (a·w2 − c·w1) / D

The plate computes these for the white dot. They are the coordinates of w in the basis (v1, v2). Move v1 and v2 and w stays put while its coordinates change: the vector is one thing, and its coordinates are a description of it relative to a choice of basis. That distinction is the one Book XXI needs when it asks which descriptions of a system are descriptions of the same system.

4 · Exercises

  1. Show that if v1 = 0, the pair is dependent whatever v2 is.
  2. Find the coordinates of (3, 1) in the basis (1, 1), (1, −1) by the formulas, then check by recombining.
  3. Three vectors in the plane are always dependent. Using the plate as a guide, give an argument that does not use any dimension count.
  4. The trace a + d is not the independence criterion. Find a pair with a + d = 0 that is independent and a pair with a + d ≠ 0 that is dependent.
  5. Describe the span of a dependent pair that is not both zero.
