# collab/ — collaborations

Working notes written with, or for, other mathematicians. One folder per collaboration.
Published at https://totogt.github.io/geometry/collab/

| folder | subject | reader | status |
|---|---|---|---|
| `pinot-orthogonal-quivers/` | affine orthogonal quiver varieties at δ and 2δ, and their contact links (on V. Pinot, arXiv:2609.39434) | Victor Pinot (Université de Lille) | v0.2, 2026-10-05, awaiting evaluation |

Each folder holds:
- `index.html` — the landing page (EN/PT/FR where useful), with one-click downloads;
- `index-verify.py` — the page's verify script (R6): numbered blocks, PASS/FAIL, an [HONESTY] block;
- `papers/` — PDFs and their LaTeX sources; `scripts/` — every script and Lean file the page names;
- a zip of `scripts/` for readers who want everything at once (also attached inside each PDF).

House rules for collaborations (shown on `collab/index.html`): every statement tagged; every number
from a script beside the page; collaborators named only with consent and never spoken for; dated
versions, corrections in dated boxes; text CC BY-NC-ND 4.0, code MIT, joint work as agreed.
