Cantor and Crossing Infinities

A popular article on Cantor, checked, proved and applied to language

Read a short article about Georg Cantor as an argument, check its facts, learn the mathematics it summarises (bijection, the diagonal, Cantor's theorem), and test a draft that uses it to talk about language learning. Written 2026-11-10.

Part 1

Part 2

The article, in six boxes

One reader’s reconstruction. Check it against the article and correct it.

BoxWhat the article offers
ClaimCantor proved that infinity comes in different sizes, and that the sizes form an endless hierarchy.
GroundsA definition of “same size” for infinite sets (a one-to-one pairing); one worked pairing of the natural numbers with the integers; the diagonal argument and Cantor’s theorem, both named and linked but not proved.
WarrantIf two finite sets are the same size exactly when their members can be paired off, the same test may be used for infinite sets. This step extends a definition; it is not forced, and it is the step Cantor’s critics could question.
BackingA list of reference pages and videos, and links to standard definitions. The article does not cite Cantor’s own papers.
QualifierThe article says it explains “briefly” and covers cardinality only. Its last sentence then drops all qualification (“absolutely mind-blowing”).
RebuttalThe opposition of Kronecker is told as a story of delays and insults. The article does not state what the objection to infinite sets was, so a reader cannot weigh it.
What to notice. The strongest claim (an unending hierarchy) rests on a theorem the article states but does not prove. Part 4 supplies the proof, so you can check the claim yourself.

Part 4

Learn the mathematics

4.1 Same size without counting: the bijection

Two sets have the same cardinality if there is a bijection between them: a rule that sends each member of one set to exactly one member of the other, hitting every member once. For infinite sets this is the only available test. Here is the article’s example, with N = {0, 1, 2, …}:

n012345678
f(n)0−11−22−33−44

Every integer appears once: the negatives come from the odd n and the non-negatives from the even n. So N and Z are the same size, although Z seems to have “twice as many” members. Task 1: find f(9) and f(10), then say which n gives −100.

4.2 The diagonal, on a small example

Suppose five numbers between 0 and 1 are listed, and we look at their first five digits:

r10.31415
r20.27182
r30.57521
r40.41421
r50.14142

The diagonal digits (first of r1, second of r2, and so on) are 3, 7, 5, 2, 2. Change each one by a rule: write 5, unless the digit is 5, and then write 6. This gives d = 0.55655. It differs from r1 in the first digit, from r2 in the second, and so on, so it differs from every number on the list. With an infinite list the same construction gives a number not on it. The article says only “change it”; the 5-or-6 rule matters because it avoids the digits 0 and 9, and so avoids the problem that 0.4999… and 0.5000… are the same number.

4.3 Cantor’s theorem, with its proof

Theorem. For every set X, there is no function from X onto its power set P(X) (the set of all subsets of X). So |X| < |P(X)|.

Proof. Suppose f maps X onto P(X). Let D be the set of those x in X that are not members of f(x). Since f is onto, D = f(y) for some y. Is y in D? If y is in D, then by the definition of D, y is not in f(y) = D. If y is not in D, then y is in f(y) = D. Both cases are contradictions. So no such f exists. ■

For finite sets this is easy to see, because a set with n members has 2n subsets:

n = |X|012345
|P(X)| = 2n12481632

The proof above shows the same thing for infinite sets, where counting no longer works. Applied to N it gives a set P(N) strictly bigger than N, and applying it again gives P(P(N)), and so on without end. Task 2: write the proof’s two cases in your own words, using the connectors suppose, since, so and both cases.

In Lean this repository states Cantor’s theorem in Orthogenesis/NestedInfinities/EightChecks.lean as a < 2 ^ a for any cardinal a. This page does not re-run that file.

Part 6

Crossing infinities in language: a draft tested

The draft post makes two claims: that a child’s vocabulary and the sentences they can form are infinite sets, and that applying grammar “crosses another” infinity. Test them in order.

StepWhat is trueSize
Words a child has learned at a given ageA finite list.finite
Words the child’s system can form (compounding, endings)Unbounded, because a compound can be compounded again. Each word is a finite string of parts.ℵ0 (countably infinite)
Sentences, with no length limitUnbounded; each is a finite string of words.ℵ0, the same size as N
Languages (sets of sentences)Every subset of the sentences is a candidate language. By Cantor’s theorem there are more of these than sentences.2ℵ0 (uncountably infinite)

Strings over a finite list of 3 parts show the pattern: there are 3, 9, 27, 81 strings of length 1, 2, 3, 4, and 120 in all up to length 4. Listing them by length and then alphabetically gives each string a place in the list, so the set of all finite strings can be paired with N. That is why adding grammar to vocabulary does not make a bigger infinity. The bigger one appears one level up, at the set of possible languages.

Revised paragraph (model text). A baby learns a finite list of words and a few rules, and the rules make the set of possible words and sentences infinite: the first crossing, from finite to countably infinite. A language is a set of sentences, and by Cantor’s theorem there are uncountably many of those: a bigger infinity. Acquiring a language means finding one among them.

Limits of the argument. This is about formal languages. The number of languages humans can actually learn is far smaller, and nothing here shows how children find one. The sentence “Cantor would have agreed” cannot be checked: no source read for this page shows Cantor writing about language acquisition. “Cantor’s theorem lets us say it exactly” can be checked, and is what Part 4 proves.

Task (200 words). Rewrite the draft’s opening paragraph, keeping the author’s point about learning at the front, so that each claim about infinity has the right size in the table above.
