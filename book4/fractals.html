Principia Orthogona · Volume IV · Chapter 1½ · Between the first and second dimension

Fractals: the objects between one and two dimensions

Dimension between 1 and 2 Case study d = 4/3 Verifier fractals-verify.py Status algebra hand-derived; numerics run once, see §5
A line has dimension 1 and a filled square has dimension 2. Fractals are the objects that live in between, and their dimension is a number you can compute. This chapter lays out the family, then builds one member with similarity dimension exactly 4/3 and says plainly which famous curve is not that one (the Koch curve is 1.2619).
§0 · The family

Objects between dimension 1 and 2

Replace an object by N copies of itself, each scaled by a ratio r. The similarity dimension is d = log N / log(1/r). A segment cut into N pieces of ratio 1/N gives 1; a square cut into N2 pieces of ratio 1/N gives 2. Anything with a ratio in between gives a non-integer d. The table below uses exact N and r; I recomputed each value with fractals-verify.py. Similarity dimension equals the true dimension only when the pieces do not overlap much, which holds for these classical examples.

ObjectN1/rd
Koch curve431.2619
Cantor dust (4 squares of side 1/3)431.2619
Tent curve (this chapter)423/21.3333

Two things to keep straight. Dimension in this sense is a measure of how an object fills space, not whether it is a curve: the Cantor dust is totally disconnected yet sits at 1.26, and the carpet has zero area yet sits near 1.89. Also, a single construction can sweep through the whole range. Keep four pieces and let the ratio change: the tent family below has d = 1.0000 at θ = 0°, 1.0256 at 15°, 1.1158 at 30°, 1.3333 at 45°, and 1.6694 at 55° (similarity dimension; an upper bound once pieces start to overlap). The rest of the chapter takes the 45° member, because it is the one that gives exactly 4/3.

§1 · The answer first

Which one is 1.333?

Not the Koch curve. Koch replaces each segment by four pieces each one third as long, so d = log 4 / log 3 = 1.2619. To get 4/3 with four pieces you need pieces of length r with log 4 / log(1/r) = 4/3, which gives 1/r = 43/4 = 23/2 ≈ 2.828. The curve below uses exactly that ratio: four pieces, each 2−3/2 times the parent.

As far as I know, 4/3 also appears elsewhere in the literature: the frontier of planar Brownian motion, the exponent of the two-dimensional self-avoiding walk (ν = 3/4), and the SLE8/3 curve (1 + κ/8). I have not checked any of those here. They share a number with our curve, not a construction and not an invariant.

§2 · Construction

The tent curve

Take the unit segment from 0 to 1 in the plane. The generator replaces it by four straight pieces through the points (0,0), (¼,¼), (½,½), (¾,¼), (1,0): two pieces rising at 45°, two falling at 45°. Each piece has length ¼·√2 = 2−3/2. To refine a level, replace every piece by a copy of the generator carried onto it by the rotation-and-scaling that sends the unit segment to that piece (an orientation-preserving similarity). The curve is the limit of the levels.

§3 · Dimension and length

Hand derivation

The similarity dimension d solves N rd = 1 with N = 4 and r = 2−3/2. Then 4 · 2−3d/2 = 1, so 22 − 3d/2 = 1 and d = 4/3. At level n the polygon has length (N r)n = (√2)n, which grows without bound.

N r = 4 · 2^(−3/2) = 2^(1/2) = √2
d = log N / log(1/r) = (2 log 2)/((3/2) log 2) = 4/3
length at level n: L_n = (√2)^n → ∞ (a rectifiable limit would have finite length)

Two caveats the formula does not remove. First, similarity dimension equals the true (Hausdorff) dimension only when the pieces overlap little (an open-set condition); I have not proved that condition for this curve, only checked it numerically to level 5 (§5). Second, I looked only at the 45° member. In a family with apex angle θ the ratio is r = 1/(4 cos θ) and the similarity dimension is log 4 / log(4 cos θ); other angles give other dimensions, but the formula is only an upper bound once pieces overlap, and I have not determined where that begins (my floating-point scan of other angles was unreliable, see §5). 45° is the case where the answer is exactly 4/3 and the exact check above was run.

§5 · What was and was not checked

Verifier output

I ran fractals-verify.py on the repository machine. It builds the levels with exact complex-number similarities and reports the following.

generator pieces: all 0.353553 = 2^-1.5 d = log4/log(1/r) = 1.3333333…
level length, measured vs √2^n: n=0..6 agree to 6 decimals (1, 1.414214, 2, 2.828427, 4, 5.656854, 8)
proper self-crossings, levels 1–5 (exact rational arithmetic): 0, 0, 0, 0, 0
touching non-adjacent pairs, levels 1–5: 0, 0, 12, 70, 316
box-count slope, Koch (true 1.2619): 1.318 tent (true 1.3333): 1.260

So the algebra and the length are exact, and no pieces properly cross through level 5. But the exact check also shows the curve touches itself from level 3 on (12, 70, 316 touching pairs at levels 3, 4, 5), so the limit is not a simple arc. Touching is compatible with the open-set condition, which only forbids substantial overlap, but I have not proved it; this is a finite check, not a proof. I caught this because a floating-point version of the same test gave nonzero crossing counts at level 5: the touch points are exactly where rounding error flips the answer, so floating-point crossing counts are unreliable for this curve and should not be quoted. The box-count slopes are off by about 0.06 in opposite directions for the two curves, so box counting at these scales cannot distinguish 1.26 from 1.33. I report it as a sanity check on the code, and I do not offer it as a measurement of the limit. The verifier is untested by anyone but me until you run it yourself: python3 fractals-verify.py.

Touching pairs between non-adjacent pieces, counted in exact integer arithmetic (fractals-touch-count.py), levels 3 to 8: 12, 70, 316, 1310, 5348, 21550, with 0 proper crossings at every level. The level-to-level ratios are 5.83, 4.51, 4.15, 4.08, 4.03, and touching pairs per piece settle near 0.33 (0.19, 0.27, 0.31, 0.32, 0.326, 0.329). Observation only: I have no proof that the ratio tends to 4 or that the per-piece value tends to 1/3. A bounded number of contacts per piece would be consistent with the open-set condition, but is not a proof of it.

§6 · Where this meets Book 4

The formula in Theorem 3.4

The Cluster-plasma entry in the GOMC Opus notes states df = 1 + log μ / log λ, with μ a fold-depth and λ a compression ratio. For our curve write μ = N r = √2 (the length gained per level) and λ = 1/r = 23/2. Then 1 + log μ / log λ = 1 + (1/2)/(3/2) = 4/3, the same value as above. This shows the formula is a rewriting of the similarity-dimension identity d = 1 + log(N r)/log(1/r). It does not verify anything about Cluster data, where the quoted range is df ≈ 1.6–1.8; that would need μ and λ measured from the data, which this chapter does not do.

Shared functional form, not a shared invariant. Many unrelated systems give the same number or the same formula; that is not evidence of a common mechanism.
