Is there a selection law beyond energy minimization? — dynamical accessibility analysis (published 2026-11-26 for review; negative-leaning, nothing tested)

Tags: [A] analytical · [L] literature (recalled, not re-fetched unless stated) · [C] conjectural · [S] specification only.

1. What already exists in the Opus (from project records) and what would be new

Exists:

  • TOGT definition: topography = structure of admissible paths; orthogenesis = selection of the realized path among admissible ones (Book 8 Ch 14 §8, generation-under-constraint, ch7-topological-orthogenesis). Ch 14 Thm 5 gives an exact example of "topography" (admissible profiles = positive concave functions) and states plainly that it supplies no selection principle — orthogenesis there is a free input.
  • DM3: conservative contact/Reeb flows. Verified (elementary model, ReebNoAttractor, author-reported kernel check): a volume-preserving flow has no closed attracting set with smaller measure than its basin. Hence dissipation needs a separate mechanism: the Lyapunov-decay attractor in CatGT_Main §9 (relaxStep_contracts) — an energy-like descent, standard gradient-type structure.
  • FoldFlow.lean: gradient flow of a cubic fold (saddle-node normal form) — the one place a gradient flow with branch loss already appears.

    New (not in the Opus, would be fresh assumptions): a configuration manifold M of electronic occupations/orbitals; an energy functional on M (conventional atomic physics supplies one: SCF total energy); a mobility operator G(x); initial conditions x(0); any rule saying which dynamics nature follows. Not available: x*, G, C/K/F/U as operators on L²(X_cat) (project open item 3). So "the" TOGT selection operator cannot be applied to atoms from existing definitions.

2. Equilibrium selection vs dynamical accessibility [A]

Equilibrium: x*=argmin_M E. Dynamical: ẋ=−G(x)∇E(x), G⪰0 ⇒ dE/dt=−∇Eᵀ G ∇E ≤0 (T5 in FORMALIZATION-TARGETS). Facts:

  1. The flow converges (when bounded) only to critical points of E, not to the global minimum. The reached minimum depends on x(0) and on G: with G and x(0) free, any local minimum can be "selected" ⇒ no prediction. A law needs G and x(0) fixed independently.
  2. Changing G by a positive-definite reparametrization (G→SGSᵀ) does not change the set of critical points or their stability; it changes basin shapes and rates. If basin boundaries matter, G matters; if only stable endpoints matter, G is irrelevant. So any prediction beyond argmin must come from (x(0), basin geometry), which is exactly what is not independently specified.
  3. For an *isolated atom in its ground state* the physical answer is argmin E over the full quantum state space: excited and metastable states radiate/decay to the global minimum (metastable states exist but are not "ground configuration"). The ground configuration is therefore an equilibrium, not an accessibility, question. A dynamical-accessibility refinement would only matter for how an atom is *prepared* (processes), not for the periodic table of ground states. [A/physics]
  4. Integer occupation configurations form a discrete set; "local minima", "basins" and "fold bifurcations" need a continuous order parameter (fractional occupations, ensemble/Janak). For the exact functional the ground-state energy as a function of fractional electron number is piecewise linear [L: Perdew–Parr–Levy–Balduz 1982, recalled, not re-fetched]; then there is no smooth interior minimum to follow or lose. With an approximate functional, transitions would be set by the functional's convexity error — an artefact, not a prediction.

3. The one candidate law I can state without fitting — specified BEFORE any test [S]

Z-continuation (hysteresis) selection. Let E_n(Z) be the SCF total energy of configuration branch n at real nuclear charge Z (continued). Orthogenetic rule R: the preferred configuration at Z+1 is the continuation of the tracked branch n(Z) as long as that branch remains a local minimum along the continuous order parameter λ (fractional occupation transferred between the competing shells); it changes only at the Z_f where the tracked local minimum disappears (fold/saddle-node, the FoldFlow normal form). Conventional rule C: change at the crossing Z_× where another branch becomes lower. Distinguishing prediction: if the transition is first-order in λ then Z_f ≠ Z_× (hysteresis window), and the two rules predict different Z for the d- or f-block onset; if the transition is a smooth crossover (single minimum moving continuously) then R=C and TOGT adds nothing. Parameter count: zero. Inputs: the same SCF functional. Not fitted to any exception; test set must be fixed before running (e.g. all onsets of 3d, 4d, 5d, 4f filling and the 3d/4s competition), graded against established configurations as validation. Expected outcome [C]: R and C coincide for atoms (point 4: fractional-occupation energy is convex/piecewise linear ⇒ a single minimum, so no fold), i.e. no new prediction for ground-state configurations. Where R≠C would be real kinetic problems (adsorption/coke formation in zeolites, cluster isomers) — a different domain, requiring its own derivation and not to be folded into the CatGT paper (V5 cut the unifying claims for exactly this reason). Testing cost: continuous-occupation SCF on K…Cu region: moderate (the code supports fractional occupations already). Not run.

4. Verdict

  • No selection law distinct from conventional physics has emerged. The accessibility formulation is mathematically meaningful (basins, folds, hysteresis; T5) but, for isolated-atom ground configurations, either coincides with argmin or is unconstrained (free G, x(0)).
  • Therefore, at present: TOGT supplies a *geometric representation* of established atomic structure (configuration space + energy + selection=argmin), not an independent predictive law. Conventional spin physics fully explains the Cr result (see REVISION3-consolidated.md); TOGT cannot claim it.
  • Falsifiable commitment for any future TOGT law: state (M, E, G, x(0)) with no free parameters, name the observable where it differs from argmin, and run only then.
