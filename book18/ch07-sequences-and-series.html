Sequences and Series

What it means for an infinite sum to have a value, and the three facts that settle most cases: the geometric series, a bounded monotone sequence, and comparison with a larger series. Each is stated the way a textbook states it and checked by the Lean kernel.

An infinite sum is not a sum. Adding infinitely many numbers is not an operation anyone can carry out, so the value of a series is defined as the number its partial sums settle down to, if they settle at all. Everything in this chapter is a consequence of that one definition.

§ 1

What “converges” says

A sequence s0, s1, s2, … converges to L when, for every tolerance ε > 0, there is a place N after which every term is within ε of L: |sn − L| < ε for all n ≥ N. The series a0 + a1 + … converges to L when its partial sums Sn = a0 + … + an−1 do.

The Lean file states exactly this, as ConvergesTo and partialSum, and its first theorem, convergesTo_iff, proves the definition equal to Mathlib's own notion of a limit. That theorem is there so that every other statement in the file can be read against the definition above and not against a name.

§ 2

The geometric series

For r ≠ 1, multiply Sn = 1 + r + … + rn−1 by r and subtract: everything cancels except the ends, so (1 − r)Sn = 1 − rn and Sn = (rn − 1)/(r − 1). When |r| < 1 the number 1/(1 − r) is the candidate limit, and the distance from it is exact:

The error, exactly |Sn − 1/(1 − r)| = |r|n / |1 − r|.
Since |r|n falls below any positive number once n is large enough, the partial sums converge to 1/(1 − r).

For r = 1/2 this gives Sn = 2 − 21−n: below 2 at every step, and as close to 2 as you like. The script checks both formulas in exact fractions for several values of r (including a negative one) and finds, for ε = 10−6, the place N from which the error stays below ε.

In Lean this is geom_partial_sum and geom_series_converges. The second is proved by calling Mathlib's lemma for the geometric series, not by re-deriving the error formula above, so the hand argument and the machine proof are two routes to the same statement and the file does not contain the hand one.

§ 3

A bounded monotone sequence converges

Suppose s0 ≤ s1 ≤ … and no term exceeds a fixed number M. The completeness of the real numbers says the set of terms has a least upper bound L. Given ε > 0, the number L − ε is not an upper bound, so some sN > L − ε. From there on the sequence never decreases and never passes L, so L − ε < sn ≤ L for all n ≥ N. That is convergence to L.

The script runs the example sn = 1 − 1/(n+1): it is increasing and bounded by 1, and for ε = 1/10, 1/1000, 10−6 the place N = 1/ε works. In Lean the statement is bounded_monotone_converges, again proved with Mathlib's lemma for a monotone sequence bounded above.

§ 4

Nonnegative terms, and comparison

If every term of a series is nonnegative, its partial sums can only grow. By § 3 they converge as soon as they are bounded. That is nonneg_series_bounded_converges. The comparison test follows in one line: if 0 ≤ an ≤ bn and the partial sums of b are bounded, then so are those of a, and a converges.

An example the script checks in exact arithmetic: 1/(i+2)2 ≤ 1/((i+1)(i+2)), and the larger series telescopes, because 1/((i+1)(i+2)) = 1/(i+1) − 1/(i+2), to 1 − 1/(n+1), which never exceeds 1. So the series of 1/(i+2)2 has bounded partial sums and converges. The chapter does not say what it converges to.

§ 5

Two controls, and what they are for

A theorem with a hypothesis is only informative if the hypothesis can fail. The partial sums of the constant sequence 1 are n, which exceeds every bound, so the boundedness hypothesis in § 4 really excludes something. The Lean file proves that as control_constant_unbounded, and the second control, control_half_geometric, confirms the geometric theorem gives 2 for r = 1/2.

Nonnegativity is also needed. The terms (−1)n have partial sums 1, 0, 1, 0, …, which are bounded and have no limit, because consecutive partial sums always differ by 1. The script checks this. The Lean file does not prove it. It is an illustration, and the chapter marks it as one.

§ 6

What is not here
