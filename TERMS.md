# TERMS.md — declared vocabulary

Every coined term in this corpus, in the form `Expansion (ACRO)`, as of 2026-08-22.
`tools/terms.py --check` fails on any term used but not declared here.

**This is a baseline, not an endorsement.** It records the vocabulary that exists,
exactly as `Orthogenesis/Architecture/KNOWN_PLACEHOLDERS.txt` records the vacuous
statements that exist. Some entries below are author affiliations, language tags or
standard field acronyms caught by the pattern; pruning them is a later pass. The
purpose is not to judge a term — no checker can — but to make a *new* one visible.

Why it exists: on 2026-08-22 a Google AI Overview described this corpus as using a
"Log-Psi Recurrence Operator" and "Harmonic Resonance Bands (HRB)". Neither term
occurs anywhere in it. Confabulated vocabulary arrives in the credible form, and if it
is ever pasted into a page, a deposit description or an abstract, nothing here would
have reported it. Now something does.

## Disowned — attributed to this corpus, and not used by it

A term in this list is **not** vocabulary of this corpus. It is recorded because
something outside the corpus attributed it here. Each entry names the files
permitted to *mention* it; `tools/terms.py --check` fails if it appears anywhere
else, and that failure is louder than an ordinary undeclared term, because it
means a confabulation has been absorbed rather than merely reported.

The distinction is use versus mention. Writing down that a term is not ours is a
mention. Building on it would be a use. The first form of this checker could not
tell them apart: it skipped `TERMS.md` by name so the rationale at the top of
this file would not trip it, but `CLAUDE.md` records the same episode, and CI
run #247 failed on that sentence — the corpus penalised for saying, accurately,
that the term is not its own.
