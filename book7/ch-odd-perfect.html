Can a Perfect Number Be Odd?

Add up the divisors of 28 and you get 28. Every perfect number anyone has found is even. Nobody has proved that an odd one cannot exist, and nobody has found one. This page lets you do the sums, and shows exactly how far the searching has gone here.

Three kinds of statement

Each claim on this page carries one of these labels. THEOREMPROVED is proved, here or in a cited source. CHECKED INSTANCECOMPUTED is a finite computation: true for the cases run, silent about the rest. OPEN QUESTIONOPEN is not known. A fourth, CITED RESULTCITED, marks published results that are reported here but not re-derived. Lean and Mathlib names appear only where a source file was read, and the page says which.

The whole story is on this page without scripts: the live controls below recompute the same quantities, and the numbers a visitor sees on first load are written into the HTML.

1. Add up the divisors

THEOREMPROVED (definition, not a result) A positive integer $n$ is perfect when the sum of its divisors smaller than $n$ equals $n$. Write $s(n)$ for that sum; $n$ is perfect when $s(n)=n$.

28: 1 + 2 + 4 + 7 + 14 = 28 s(28) = 28 perfect 12: 1 + 2 + 3 + 4 + 6 = 16 s(12) = 16 abundant (sum is larger) 9: 1 + 3 = 4 s(9) = 4 deficient (sum is smaller)

Divisors come in pairs $d \leftrightarrow n/d$, so a program only has to look up to $\sqrt n$. The one trap is a square: its square root pairs with itself and must be counted once, not twice.

28: 1 + 2 + 4 + 7 + 14 = 28. s(28) = 28, so 28 is perfect.

CHECKED INSTANCECOMPUTED $s(1)=0$, so 1 is not perfect. $s(9)=4$ and $s(25)=6$ (square roots counted once). $s(36)=55$. $s(6)=6$, $s(28)=28$, $s(496)=496$. Printed by tools/odd_perfect_check.py.

2. Every even perfect number comes from one recipe

THEOREMPROVED If $2^p-1$ is prime, then $2^{p-1}(2^p-1)$ is perfect (Euclid, Elements IX.36; worked out on the Euclid chapter). Conversely, every even perfect number has this form (Euler's converse; the statement Theorems100.Nat.even_and_perfect_iff is in the Mathlib Archive file Archive/Wiedijk100Theorems/PerfectNumbers.lean, read at local checkouts 4bbdccd9c5 and eba3d887fc, not at this corpus's pinned revision).

So finding even perfect numbers is the same job as finding primes of the form $2^p-1$, called Mersenne primes. Two facts about the exponent: if $p$ is composite then $2^p-1$ is composite (if $p=ab$ then $2^a-1$ divides it), so only prime $p$ need be tried; and the converse fails, since $p=11$ is prime but $2^{11}-1 = 23\times 89$.

The test used for large exponents is Lucas–Lehmer. For an odd prime $p$, set $s_0=4$ and $s_{k+1}=s_k^2-2 \bmod (2^p-1)$; then $2^p-1$ is prime exactly when $s_{p-2}=0$. The test is defined for odd $p$. The exponent $p=2$ must be handled on its own: run mechanically it takes zero steps, ends at $s_0=4\neq0$, and would wrongly call $3$ composite. Here $p=2$ is answered directly: $2^2-1=3$ is prime, and $N=2\cdot 3=6$.

p = 5, 2^5 − 1 = 31 5 is prime. Lucas–Lehmer: s0 = 4, s1 = 14, s2 = 8, s3 = 0, so 31 is prime. N = 2^4 × 31 = 496. Brute-force divisor sum of 496: 496. Perfect.

3. Search for an odd perfect number, with the limits showing

A search is a finite thing. The control below computes $s(n)$ for every $n$ from 1 through the limit you choose, then reports how many odd numbers it tested and how many were perfect. Whatever it reports, it describes that interval and no other.

Press Search. Until you do, the static result below is the one this page was written with.

CHECKED INSTANCECOMPUTED Static result from tools/odd_perfect_check.py: the positive odd integers from 1 through 999,999 inclusive, which is 500,000 candidates, contain 0 numbers with $s(n)=n$. The same interval, odd and even together, contains exactly four perfect numbers: 6, 28, 496 and 8128. The next even one, 33,550,336, is outside it.

This is a statement about 500,000 numbers. It is not evidence about the number 1,000,001, and it is not a proof about any number beyond the interval.

4. What is known, and what is not

OPEN QUESTIONOPEN Does an odd perfect number exist? No example is known, and no proof that none exists is known.

CITED RESULTCITED P. Ochem and M. Rao, “Odd perfect numbers are greater than $10^{1500}$”, Mathematics of Computation 81(279), 2012: any odd perfect number would exceed $10^{1500}$. Existence of the paper and the title were confirmed from the AMS and HAL listings; the argument was not re-derived or checked for this page.

CITED RESULTCITED Euler's form: an odd perfect number, if one exists, must look like $p^{e}m^2$ with $p$ a prime, $p\equiv e\equiv 1 \pmod 4$, and $p\nmid m$. This is a classical theorem credited to Euler and was not re-derived here.

Set the sizes side by side. The search in section 3 reaches about $10^6$; the published lower bound is $10^{1500}$. No search of the kind in section 3 could reach a bound like that: the numbers are too many to test one at a time.

One asymmetry is worth keeping. Checking a candidate is easy: factor $n$, compute $\sigma(n)$, compare with $2n$. A single counterexample would settle existence at once. By the cited bound, any counterexample is larger than $10^{1500}$.
