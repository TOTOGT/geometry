How to send one / Como enviar

Copy Chapter 2, translate the text and keep its tables and links. Name the file ch02- plus your language code and .html, put it in this translations folder in the TOTOGT/geometry repository, and open a pull request. Say who translated it, whether a machine tool was used, whether a speaker has checked it, and how you want to be credited. Leave blank any table cell for a language you do not speak. To add a page or chapter written in your own language, do the same with a file named for your language, for example page-gn.html. If you cannot use GitHub, send the text to the author in any form you can.

Copie o Capítulo 2, traduza o texto e mantenha as tabelas e links. Nomeie o arquivo ch02- mais o código da sua língua e .html, coloque-o nesta pasta translations no repositório TOTOGT/geometry e abra um pull request. Diga quem traduziu, se foi usada ferramenta automática, se um falante revisou e como quer ser creditado. Deixe em branco qualquer célula de uma língua que você não fala. Para acrescentar uma página ou capítulo escrito na sua língua, faça o mesmo com um arquivo com o nome dela, por exemplo page-gn.html. Se não puder usar o GitHub, envie o texto ao autor da forma que puder.
