# Book XXV translations

Put a translation of a chapter, or a page written in your own language, in this folder and open a pull request.

- Name: `ch02-<language code>.html` for a translation of Chapter 2 (for example `ch02-bo.html` Tibetan, `ch02-ne.html` Nepali, `ch02-dz.html` Dzongkha, `ch02-yrl.html` Nheengatu, `ch02-gn.html` Guarani). For a page written in your language, `page-<code>.html`.
- Keep the tables and links of the original. Leave blank any table cell for a language you do not speak.
- In the pull request, say who translated it, whether a machine translation tool was used, whether a speaker of the language checked it, whether you are happy for it to be published with the book, and how you want to be credited.
- Do not submit recordings or text that someone else has not agreed to share.

The list of filed translations is in `index.html` in this folder.
