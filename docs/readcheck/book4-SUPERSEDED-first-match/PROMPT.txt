You are the second reader in a two-reader check of a mathematics book. You have NOT seen the first reader's labels. Do not look for them.

STATEMENT SHEET (blind-statements.tsv). Each row has a SENTENCE from a book page and the Lean STATEMENT (the declaration's type, as written)
that the sentence cites. Your job is to decide whether the statement, read literally, establishes what the sentence says.
Do not assume the proof is right and do not reward the name of the declaration. Read the statement.
Fill the label column with exactly one of:
  M  the statement establishes the sentence as written
  W  the statement is weaker or narrower than the sentence (note: what is missing)
  U  the statement is about a different object than the sentence names (note: which)
  V  the statement is vacuous or trivially true (note: the trivial witness, e.g. n = 0, an empty set, `True`, `x = x`)
  N  you cannot tell, or the statement is cut off or not shown
Try to break each statement first: choose the smallest or degenerate input (0, the empty set, the zero map, a constant function) and see whether the
conclusion still holds for the wrong reason. Put what you tried in the note column. Short notes, one line.

CLAIM SHEET (blind-claims.tsv). Each row is a theorem-shaped sentence from the page with its neighbouring sentences and NO Lean statement. Decide what the
page actually gives for it, and whether it can be false as stated. Label:
  P  proved on the page (the argument is in the context shown)
  S  a sketch or an appeal to another result (note which)
  B  a bare assertion with no argument shown
  F  false or unsupported as stated (note a counterexample, or the missing hypothesis; try the smallest degenerate case first)
For statements of the form 'G is a contraction', 'converges', 'by necessity': ask what the operators are, on what space, and whether the page defines them.

NUMBER SHEET (blind-numbers.tsv). Each row has a sentence with a stated number. Recompute it from what the sentence itself states (show the arithmetic
in the note column). Label R (matches to the stated precision), X (does not match; give your value), or C (cannot recompute from what is stated).
Never copy a number from memory; compute it.

Return the same file with the last two columns filled, tab-separated, same row ids, any order. Do not add rows. If unsure, use N or C and say why.
