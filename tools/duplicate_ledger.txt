# Declared duplicate groups — geometry
#
# One chapter with two live homes is either a decision or an accident, and
# until 2026-08-25 this repository had no way to tell them apart. tools/
# duplicates.py fails on any group not listed here.
#
# Cause, stated plainly: sessions run out of context and continue on another
# account. The next session does not always see what the previous one left, or
# continues and writes into a different folder. Two copies behave identically
# until one is edited; then the corpus has two answers and no record of which
# is current. book7/ch-curie.html and book7/chcurie.html reached 516 lines
# apart that way, linked from different pages, neither naming the other.
#
# Format:  path | path [| path]   # why this pair is intended
#
# APPEND-ONLY. A retired entry is commented out with the date and reason, never
# deleted. A bare list loses its own history the moment an entry goes: the file
# would say six and carry no trace that it once said seven.
#
# Adding a line is a decision that BOTH copies are maintained. If that is not
# true, the honest move is to merge them and leave a redirect — which is what
# was done for Curie, and the redirect stub is not counted as a copy because it
# has no paragraphs of its own.
