Unit 1 · Logic and Proof

A proposition is true or false. The connectives are not (¬), and (∧), or (∨) and implies (→). The one that surprises people is the implication: p → q is false only when p is true and q is false. computed The truth table for p → q is: (T,T) gives True, (T,F) gives False, (F,T) gives True, (F,F) gives True. So a false premise makes the implication true, which is why “if the moon is cheese then 2 + 2 = 5” is true as a statement.

The contrapositive ¬q → ¬p is equivalent to p → q; the converse q → p is not. Proof methods are direct proof, contradiction, contrapositive, cases, and induction: prove the base case, then prove that the claim for n implies it for n + 1. Induction is how correctness of recursive algorithms and loop invariants (chapter 6) is proved.

Self-check State the converse and the contrapositive of “if a program has a bug, it fails some test”, and say which one is equivalent to the original.

Unit 2 · Sets, Relations and Functions

A set is a collection of distinct elements. The operations are union, intersection, difference and complement; the Cartesian product A × B is all ordered pairs. A relation on A and B is a subset of A × B. A relation on one set is an equivalence relation if it is reflexive, symmetric and transitive, and it then splits the set into equivalence classes. A function f: A → B gives each element of A exactly one value in B; it is injective (one-to-one) if different inputs give different outputs, and surjective (onto) if every element of B is hit.

This is the language of databases (chapter 4): a table is a relation, a primary key is an injective map from keys to rows, and a functional dependency X → Y says that Y is a function of X.

Self-check Is “has the same remainder mod 5” an equivalence relation on the integers? Name the classes.

Unit 3 · Counting and Combinatorics

The product rule multiplies independent choices; the sum rule adds disjoint cases. Arranging k of n distinct items in order gives n!/(n-k)! ways; choosing k of n with no order gives the binomial coefficient C(n, k) = n!/(k!(n-k)!). The pigeonhole principle says that putting more than n items into n boxes forces a box with at least two. computed C(10, 3) = 120; 5! = 120; the number of 5-card poker hands is C(52, 5) = 2,598,960. Counting underlies the size of search spaces and key spaces (chapter 0b), and the combinatorial bounds in algorithms.

Self-check How many 4-character passwords can be formed from 26 lowercase letters with repetition allowed, and how many with no repeated letter?

Unit 4 · Probability and Bayes' Rule

A probability is a number in [0, 1] assigned to events; for independent events P(A and B) = P(A)P(B), and conditional probability is P(A|B) = P(A and B)/P(B). Bayes' rule reverses a condition: P(A|B) = P(B|A)P(A)/P(B). The expected value of a random variable is the probability-weighted average of its values, and linearity of expectation holds even without independence.

computed A condition affects 1% of a population. A test detects it 90% of the time and gives a false positive 5% of the time. The probability someone who tests positive actually has it is 0.009 / (0.009 + 0.0495) = 0.1538, about 15%, not 90%. When the base rate is low, most positives are false alarms. This same logic governs spam filters, intrusion detection and the precision and recall figures of chapter 8.

Self-check Change the false-positive rate to 1% and recompute the posterior. Say why it rises so much.

Unit 5 · Sequences, Sums and Recurrences

Many running-time calculations reduce to sums. The arithmetic sum is 1 + 2 + … + n = n(n+1)/2, so a double loop that does i units of work on iteration i costs Θ(n²). The geometric sum 1 + r + … + rk = (rk+1 - 1)/(r - 1) gives, for r = 2, 2k+1 - 1. computed Check: the sum 1..100 is 5050, which equals 100 × 101 / 2.

A recurrence defines a sequence in terms of earlier terms; T(n) = 2T(n/2) + n describes merge sort and unrolls into n levels of cost n each, about n log n. Recurrences are solved by unrolling, guessing and proving by induction, or the master theorem used in chapter 6.

Self-check Use the arithmetic-sum formula to show that comparing every pair among n items does n(n-1)/2 comparisons.

Unit 6 · Graphs and Trees

A graph has vertices and edges. The degree of a vertex is its number of edges. The handshake lemma says the sum of degrees is twice the number of edges, so the number of odd-degree vertices is even. A path is a walk without repeated vertices, a cycle returns to its start, and a graph is connected if every pair has a path. A tree is a connected graph with no cycle; a tree on n vertices has exactly n - 1 edges. computed A graph with degrees 3, 3, 2, 2, 2 has degree sum 12, so it has 6 edges. Graphs model networks, dependencies and state machines, and they appear in the algorithms and project-planning chapters.

Self-check Can a graph have degrees 3, 3, 3? Use the handshake lemma to answer.

Unit 7 · Linear Algebra

A vector is a list of numbers; the dot product of two vectors multiplies matching entries and sums them. A matrix multiplies a vector or another matrix by taking dot products of rows with columns, so matrix multiplication is not commutative. The determinant of a 2 × 2 matrix [[a, b], [c, d]] is ad - bc and is zero exactly when the matrix is not invertible. Systems of linear equations are written A x = b and solved by elimination. computed With A = [[1, 2], [3, 4]] and B = [[0, 1], [1, 0]], AB = [[2, 1], [4, 3]] (it swaps A's columns), and det A = 1 × 4 - 2 × 3 = -2. Linear algebra is the working language of machine learning (chapter 8), graphics and many security primitives. For a proper graduate-level treatment, see Book XXIV, Linear Algebra for Graduate Study, in this series.

Self-check Multiply B by A (the other order) and compare with AB.

Unit 8 · Calculus for Learning

The derivative measures a rate of change: f'(x) is the slope of the tangent. Rules to know are the power rule, the sum rule, the product rule and the chain rule, which differentiates compositions and is the engine of backpropagation. For a function of several variables the gradient collects the partial derivatives and points in the direction of steepest increase; gradient descent steps the opposite way.

computed For the chapter-8 regression data x = 1..5, y = 2, 4, 5, 4, 5 and the loss mean((wx + b - y)²), the derivative with respect to w at w = 0, b = 0 is 2 · mean((wx + b - y) · x) = -26.4. A numerical check using a small step h (central difference) gives -26.4000, so the formula and the numerical slope agree.

Self-check Differentiate f(w) = (3w - 6)² and find where the derivative is zero.
